# Plus One

Link: https://leetcode.com/problems/check-if-strings-can-be-made-equal-with-operations-i/description/?envType=daily-question&envId=2026-03-29
Approach: 

➡️ Generate all possible valid swapped versions of s1

➡️ Generate all possible valid swapped versions of s2

➡️ Compare every string from s1 list with every string from s2 list

➡️ If any pair matches → return true

➡️ If no match found → return false
