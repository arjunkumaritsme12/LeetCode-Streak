# Plus One

Link: https://leetcode.com/problems/balance-a-binary-search-tree/description/?envType=daily-question&envId=2026-02-09

Approach: 

➡️ Do inorder traversal of the BST.

➡️ Store all node values in a list.

➡️ Inorder traversal gives sorted values.

➡️ Pick the middle value as root.

➡️ Left part forms left subtree.

➡️ Right part forms right subtree.

➡️ Build tree recursively.

➡️ Result is a balanced BST.
